# Zero Networks

**Zero Networks** — браузерная пошаговая стратегия о противостоянии **Корпорации** и тайной сети **Хакеров**.

Корпорация действует в условиях неполной информации: раскрывает узлы, анализирует сообщества, изолирует инфраструктуру и снижает поддержку хакеров. Хакеры вербуют участников, развивают логистические и финансовые связи, захватывают вычислительные мощности и проводят кибератаки. Чем крупнее и эффективнее сеть, тем легче её обнаружить и разрушить.

## Возможности

- Кампания на **15 ходов**, до **3 действий** для каждой стороны за ход.
- Одновременное разрешение приказов обеих сторон.
- Три режима: **Корпорация против ИИ**, **Хакеры против ИИ**, **локальная игра двух игроков по очереди**.
- Процедурно создаваемая сеть из 30–60 узлов с тремя сообществами и расчётом центральности.
- Неполная разведывательная информация для Корпорации и полный обзор для Хакеров.
- Ресурсы, внешние связи, централизация, поддержка и уровень компрометации.
- Детерминированный игровой движок с начальным seed.
- Журнал событий, экран раскрытия приказов и итоговая оценка кампании.
- График безопасности и эффективности по истории ходов.
- Полная локализация на **русский и английский языки** с сохранением выбора.
- Адаптированные названия и описания всех действий для кибертематики.

## Технологии

- **TypeScript**, строгий режим
- **React 18**
- **Vite 8**
- **SVG** для интерактивной сети и графиков
- **Vitest** для тестового раннера
- npm workspaces; отдельные пакеты движка и клиента

Серверная часть, аккаунты, база данных и сетевая игра не требуются. Вся кампания выполняется локально в браузере.

## Требования

- **Node.js 22.12 или новее** (рекомендуется актуальная LTS-версия)
- **npm 10 или новее**

## Установка и запуск

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес в терминале. По умолчанию используется `http://127.0.0.1:5173`; если порт занят, Vite выберет следующий свободный.

## Проверка и production-сборка

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

Production-файлы создаются в `packages/client/dist`.

## Основные правила

1. Каждая сторона назначает до трёх действий и подтверждает ход.
2. Приказы раскрываются и разрешаются одновременно.
3. Хакеры получают вычислительные мощности от логистических связей и деньги от финансовых связей.
4. Кибератаки используют показатели сети на начало хода.
5. Активная киберзащита Корпорации вдвое снижает эффект атак за каждое назначенное действие защиты.
6. Уровень компрометации уменьшается вдвое после каждого незавершённого хода.
7. Корпорация побеждает досрочно при полном разрушении сети или после четырёх ходов подряд с нулевой поддержкой хакеров.
8. После хода 15 итог определяется уровнем компрометации:
   - 0–20 — убедительная победа Корпорации;
   - 21–40 — небольшая победа Корпорации;
   - 41–60 — ничья;
   - 61–80 — небольшая победа Хакеров;
   - 81–100 — убедительная победа Хакеров.

Полные описания действий, стоимость и формулы находятся в [`Zero Networks Rules.md`](<Zero Networks Rules.md>). Их также можно открыть кнопкой **?** в игре.

## Происхождение правил

Zero Networks является тематической адаптацией реконструированных правил Dark Networks. Механика и стоимость действий сохранены, а названия изменены под противостояние корпорации и хакеров.

Исходные материалы не содержат полную числовую модель оригинального движка. Недостающие формулы восстановлены как домашние правила и отмечены **[H]** в документе с правилами. Они работают в текущей реализации, но требуют дальнейшего плейтестирования для оценки баланса.

Исследовательские PDF, видео и архивные скриншоты не включены в репозиторий. Перечень источников и приоритеты реконструкции приведены в файле правил.
